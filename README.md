## 📝 Sobre o Projeto
Este projeto é um Jogo de Adivinhação Numérica interativo, desenvolvido como parte do meu aprendizado prático no curso de Lógica de Programação com JavaScript da Alura.

O código foi estruturado para exercitar conceitos fundamentais do desenvolvimento web, como a manipulação de elementos do HTML através do JavaScript (DOM), o uso de funções com parâmetros e retorno, e a aplicação de lógica de controle com condicionais e recursividade.

## 🕹️ Funcionalidades
Sorteio Inteligente: O sistema sorteia um número secreto entre 1 e 10.

Dicas Dinâmicas: O jogo oferece feedbacks (se o número secreto é maior ou menor) até que o usuário acerte.

Gerenciamento de Histórico: Utiliza listas (arrays) para garantir que o mesmo número não seja sorteado repetidamente em rodadas consecutivas.

Acessibilidade: Integração com a API ResponsiveVoice para tornar a experiência mais acessível e dinâmica através de comandos de voz.

## 🛠️ Tecnologias Utilizadas
JavaScript: Lógica principal, funções e manipulação do DOM.

HTML5: Estruturação da interface.

CSS3: Estilização e responsividade.

ResponsiveVoice API: Recurso de narração por voz.
